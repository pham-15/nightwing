# API and Privacy Plan

## Google Calendar
Start here before Gmail. Use OAuth, minimum scopes, and a simple “today’s events” command.

## Gmail
Add later because email is sensitive. Start with sender, subject, date, and snippet before summarizing full content.

## Weather
Lower-risk early integration. Use a weather API key stored in a local .env file.

## Secrets
Never commit credentials.json, token.json, or .env files to GitHub. Add them to .gitignore.
